# 👹 Sahte Jumpscare - Konsantrasyon Testi

## Nasıl Çalışır?

1. Kullanıcı "Konsantrasyon testi" zanneder
2. Kırmızı noktayı takip ederken...
3. **Rastgele 8-25. saniyede** ani jumpscare patlar 💀
4. Yüksek frekanslı ses + sallanan emoji + kırmızı flaş

## Kullanım

Sadece `index.html` dosyasını tarayıcıda aç. Sunucu gerekmez.

## Paylaşım İçin

- Arkadaşa şöyle gönder: *"Bu konsantrasyon testini yaptım, sen de dene!"*
- Link olarak paylaş
- Vercel'e deploy ettiysen oradan link ver

## Özellikler

- ✅ Tamamen HTML/CSS/JS — kurulum yok
- ✅ Ses efekti (Web Audio API)
- ✅ Rastgele emoji + mesaj her seferinde farklı
- ✅ Jumpscare zamanı her seferinde farklı
- ✅ Paylaş butonu
- ✅ Sonuç ekranı (korktu mu / dayandı mı)
